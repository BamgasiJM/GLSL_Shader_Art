# Shader Art 06: Kishimisu 1 - 기술 분석

## 개요
이 프로젝트는 **Signed Distance Field(SDF)**를 활용한 반복적 프랙탈 패턴과 **코사인 그래디언트(Cosine Gradient)** 색상 애니메이션으로 만들어지는 추상 미술 작품입니다. 별(오각형) 도형의 SDF를 반복 생성하고, 시간 흐름에 따라 색상과 애니메이션이 변하는 구조입니다.

---

## 핵심 메커니즘

### 1. SDF (Signed Distance Field)

```c
float sdPentagram(in vec2 p, in float r) {
    // 벡터 v1, v2, v3: 오각형의 기하학적 특성을 정의하는 상수
    p.x = abs(p.x);  // 좌우 대칭성 활용
    p -= 2.0 * max(dot(v1, p), 0.0) * v1;  // 첫 번째 미러링
    p -= 2.0 * max(dot(v2, p), 0.0) * v2;  // 두 번째 미러링
    p.x = abs(p.x);
    p.y -= r;
    // 최종 거리 반환
    return length(p - v3 * clamp(...)) * sign(...);
}
```

**SDF의 원리:**
- 공간의 모든 점에서 가장 가까운 도형까지의 거리를 저장
- 음수(도형 내부) / 양수(도형 외부) 구분
- 거리 값을 이용해 경계선을 매끄럽게 표현

**오각형(Pentagram) 구현:**
- 복수의 미러링(reflection) 연산으로 5개 꼭짓점 구조 모사
- `dot(v, p)` 연산으로 특정 방향에 대한 투영
- 부호 있는 거리로 도형의 내부/외부 정확히 판별

### 2. 반복 렌더링과 프랙탈 효과

```c
for(float i = 0.0; i < 3.0; i++) {
    uv = fract(uv * 1.5) - 0.5;  // 좌표 반복 및 타일링
    float d = sdPentagram(uv, 0.1);  // SDF 계산
    // 색상과 효과 누적...
    finalColor += col * d;  // 누적 합성
}
```

**동작 원리:**

1. **`fract(uv * 1.5)`**: 좌표를 1.5배 확대 후 소수 부분만 추출
   - 공간이 타일 형태로 반복
   - 매 반복마다 확대 → 프랙탈 스케일 변환

2. **`- 0.5`**: 타일링된 좌표를 중심 기준으로 재정렬
   - 타일 중심이 (0.5, 0.5)에서 (0, 0)으로 이동
   - SDF 계산에 유리한 좌표계

3. **누적 합성**: 반복마다 결과를 더함
   - 작은 별에서 시작 → 점점 큰 별 표현
   - 깊이감 있는 프랙탈 구조

### 3. 빛 효과 (Glow)

```c
d *= exp(-length(uv0));  // 중심부로 갈수록 거리 감소

d = sin(d * 8.0 + u_time) / 8.0;  // 시간에 따른 파동
d = abs(d);  // 음수를 양수로 변환

d = pow(0.01 / d, 1.3);  // Glow의 핵심: 역수 함수
```

**Glow 메커니즘:**

1. **`sin(d * 8.0 + u_time)`**: 
   - 거리 값에 정현파 진동 추가
   - `u_time` 항으로 시간 흐름에 따라 변함
   - 별의 경계선이 "맥동"하는 효과

2. **`pow(0.01 / d, 1.3)`**:
   - `0.01 / d`로 거리의 역수 계산
   - `d`가 작으면(경계선 근처) 큰 값
   - `d`가 크면(거리 멀면) 작은 값
   - 1.3 거듭제곱으로 강조 → 경계선 근처가 매우 밝음

**결과:** 별 경계선 주변이 강한 발광 효과

### 4. 코사인 그래디언트 색상 팔레트

```c
vec3 palette1(float t) {
    vec3 a = vec3(0.614, 0.608, 0.340);
    vec3 b = vec3(0.905, 0.258, 0.284);
    vec3 c = vec3(1.479, 0.644, 0.859);
    vec3 d = vec3(0.552, 1.583, 4.770);
    return a + b * cos(6.28318 * (c * t + d));
}
```

**원리:**

코사인 함수의 주기성을 이용한 색상 생성:

```
color = a + b * cos(2π * (c * t + d))
```

각 채널(R, G, B)에서:
- `a`: 베이스 색상
- `b`: 진폭 (색상의 변화 범위)
- `c`: 주파수 (색상의 주기)
- `d`: 위상(phase) 시프트

**장점:**
- 부드러운 색상 전환
- 주기적이므로 애니메이션에 자연스러움
- RGB 채널마다 다른 주파수 → 복잡한 색감

**사용:**
```c
vec3 col = palette1(length(uv0) + i * 0.4 + u_time * 0.5);
```
- `length(uv0)`: 화면 중심부터의 거리 기반 색상
- `i * 0.4`: 반복 레이어마다 다른 색상
- `u_time * 0.5`: 시간에 따른 색상 애니메이션

## 시각적 구조

```
중심부
  ↓
첫 번째 반복: 작은 별 1.5배 확대
  ↓ (fract로 타일 반복)
두 번째 반복: 더 큰 별 1.5배 확대
  ↓
세 번째 반복: 가장 큰 별 1.5배 확대
  ↓
Glow 효과: 경계선 주변 밝아짐
  ↓
색상 애니메이션: 코사인 그래디언트로 부드럽게 변화
```

---

## 애니메이션 메커니즘

### 시간 기반 변화 요소

1. **별의 맥동**
   ```c
   d = sin(d * 8.0 + u_time) / 8.0;
   ```
   - `u_time`이 증가하면서 sine 파동이 위상 이동
   - 별의 경계선이 영상으로 파동침

2. **색상 회전**
   ```c
   vec3 col = palette1(...+ u_time * 0.5);
   ```
   - `u_time * 0.5`로 색상이 시간에 따라 변함
   - 코사인 함수 때문에 부드럽게 순환

## 핵심 기술 요약

| 기술 | 목적 | 구현 |
|------|------|------|
| **SDF** | 별(오각형) 도형 정의 | 기하 계산 + 거리 함수 |
| **반복(Tiling)** | 프랙탈 스케일 구조 | `fract(uv * 1.5)` |
| **역수 Glow** | 경계선 발광 | `pow(0.01 / d, 1.3)` |
| **Cosine Gradient** | 색상 팔레트 | `a + b * cos(6.28318 * ...)` |
| **누적 합성** | 깊이감 있는 이미지 | `finalColor += ...` 루프 |

이 아트워크는 **기하학적 거리 함수(SDF)**와 **삼각함수 기반 색상 애니메이션**의 조합으로 만들어집니다:

1. **SDF Pentagram**: 정확한 도형 표현
